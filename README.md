
Шаг 2: Запуск

Запустите окружение одной командой (скачивание образов займет меньше минуты, так как используются alpine-версии):
bash
docker compose up
Используйте код с осторожностью.

📊 Результат проверки

• Команда docker compose ps покажет все 7 контейнеров (1 Redis, 2 Menu, 2 Order, 1 Frontend, 1 Nginx) в статусе Up (healthy).
• Вы можете открыть браузер на http://localhost и увидите страницу-заглушку фронтенда.
• Любые изменения количества реплик через docker compose up --scale menu-service=4 -d мгновенно обработаются балансировщиком nginx без перезапуска последнего.
